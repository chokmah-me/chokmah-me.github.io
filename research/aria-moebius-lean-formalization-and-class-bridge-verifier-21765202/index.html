Abstract

This deposit is the Lean 4 and Python companion to Mobius Bridges for the Invert-and-Affine S-box Class, with the Four ARIA Instantiations (paper v1.0.5). The Nasr–Carlini Möbius Bridge is not specific to the AES S-box: it holds for every S-box of the form S = L2 ∘ Frobj ∘ inv ∘ L1, with the Frobenius exponent j as the only degree of freedom. ARIA instantiates four members of that class at once (S1, S2, S1−1, S2−1 at j = 0, 3, 0, 5).

The v1.0.3 zip contains Bridge.lean / AriaMobius.lean (Lean 4.32.2, mathlib v4.32.2) formalizing Theorem 3.1, Corollary 3.2, and the §5 bad-index set, plus verify_bridge_class.py, which runs five exhaustive GF(28) checks (0/64770 mismatches per ARIA Table 1 row with published A, B, a=0x63, b=0xE2). Axiom set: propext, Classical.choice, Quot.sound; no sorry. Prefer the software concept DOI for the always-latest zip. Cite the paper for the theorem. No attack complexities for ARIA are claimed.
