Abstract

Google's 2026 magic-state cultivation experiment on Willow grafts a cultivated magic state from a distance-3 color code into a distance-5 code. In the grafted-code memory experiment, the logical error rate is about seven times a depolarizing simulation that omits leakage. The authors call leakage the likely main cause and ran no removal experiment. Variability in physical qubit performance is a separate route and does not by itself predict the leakage signatures. The public deposit has no files for the nine-cycle run. A pre-registered 2 by 2 has not been run. Until it runs, the attribution stays likely and not ablated.
