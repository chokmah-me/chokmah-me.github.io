chokmah-me/hashline: hashline 0.4.1

dyb · 2026-06-19 · software · cc-by-4.0

Version of record (canonical): https://doi.org/10.5281/zenodo.20766159

Abstract

Patch release fixing two Windows / non-UTF-8 console encoding bugs in the CLI, found while using the harness on an emoji- and symbol-heavy repo: 🐛 hashline read crashed with UnicodeEncodeError when printing files containing non-cp1252 characters (≥, emoji, …). 🐛 hashline apply reading a patch from stdin silently double-encoded non-ASCII content (em-dashes → mojibake) because stdin used the platform default encoding instead of UTF-8. Both fixed by forcing UTF-8 on stdin/stdout/stderr at CLI startup. Added subprocess regression tests pinning the read and stdin-apply paths under a simulated non-UTF-8 console. See CHANGELOG.md.
