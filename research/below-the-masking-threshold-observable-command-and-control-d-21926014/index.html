Below the Masking Threshold: Observable Command-and-Control Discrimination in a Residual IRGC Missile Force

Abstract

After high week-one attrition, an open-source attribution-correlation proxy can discriminate active from pre-programmed C2 in a residual IRGC missile force under sparse provocation. Dense provocation saturates that proxy (H_ceiling). Attribution correlation is a proxy, not the emergent target ratio, and is not a standing C2 indicator.

This record is the Phase II companion preprint (v0.3 PDF). Simulation code lives on the software concept 10.5281/zenodo.19210120. Prefer paper concept DOI 10.5281/zenodo.21865793 for the always-latest PDF.
