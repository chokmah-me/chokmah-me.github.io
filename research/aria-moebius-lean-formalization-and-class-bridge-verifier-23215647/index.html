Abstract

The Nasr–Carlini Möbius Bridge is not specific to the AES S-box. It holds for every S-box of the form S = L2 ∘ Frobj ∘ inv ∘ L1, with L1, L2 GF(2)-affine bijections and the Frobenius exponent j as the only degree of freedom. ARIA instantiates four members of that class at once (S1, S2, S1−1, S2−1 at exponents 0, 3, 0, 5). This deposit is the Lean 4 formalization and exhaustive GF(28) Python verifier for that class identity.
