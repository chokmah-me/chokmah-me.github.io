fast16 as a Second-Order Subversion Attack

Bilar, Daniyel Yaacov · 2026-05-03 · publication/preprint · cc-by-4.0

Abstract

SentinelOne's April 2026 disclosure of fast16, a 2005 kernel-mode framework that corrupts floating-point calculations in engineering simulation software, is classified as a second-order subversion attack: the high-precision end system is reached through the OS filesystem stack and the simulation tool above it.

fast16.sys disables the Windows Prefetcher so a filesystem filter sees every EXE read, delays patching until explorer.exe opens, and checks for a long AV list before installing. The wormlet is delivery, not a distinct ancillary hop. The classification yields defenses (hardware-rooted driver attestation, diverse independent toolchains, air-gapped reference baselines) from the nth-order framework rather than the incident report.
