Secure SDLC & AI-Assisted Engineering

A private, tailored multi-session curriculum from Chokmah LLC for engineering and security teams that use AI coding assistants and need those practices to sit inside a defensible secure software development lifecycle—not ad-hoc “vibe coding.”

Instructor: Dr. Daniyel Yaacov Bilar (dyb) · Provider: Chokmah LLC

Curriculum facts

  • Delivery: private (team or closed cohort); schedule arranged per engagement
  • Focus: secure SDLC with AI coding assistants, review gates, threat modeling for generated code
  • Customization: hyper-customized to stack, domain constraints, and compliance posture
  • Materials: participant materials only—not a free public kit

What you learn

1. Secure SDLC with AI in the loop

Where generation fits (and fails) in requirements, design, implementation, review, and release. Explicit human-on-the-loop checkpoints.

2. Prompt and review discipline for production code

Task framing, constraint headers, and critique habits so AI-assisted changes remain reviewable and attributable.

3. Threat modeling for AI-generated artifacts

Attack surface introduced by the generation process itself: injection into prompts/context, hallucinated controls, supply-chain and model-choice assumptions.

4. Validation and compliance-oriented automation

Patterns for checks, logging, and evidence so automation supports auditability rather than bypassing it.

Who this is for

Security engineers, platform/AppSec leads, and engineering managers adopting Claude, Kimi, or other coding assistants who need domain-compliant process—not demos alone.
