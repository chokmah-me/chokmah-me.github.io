FROM FUNCTION TO REGIME

AttestationRegimeClassifier · Ghidra

16 May 2026 · software

The plugin does not invent the three regimes. It labels each firmware function with the regime the theory already named.

KEY INSIGHT

A Ghidra pass classifies embedded and ICS firmware functions into formally provable, statistically testable, or adversarial-input exposure.

DISTINCT FROM THE PAPER

The three-regimes paper gives the query bounds. This record is the classifier that stamps those labels onto firmware.

LIMIT

Static labels are not a proof the function meets the bound. A Regime 3 tag means the path needs a harder check, not that the check was run.

WHAT THE STAMP MEANS

  • Formally provable: the function is a candidate for a proof, not a proof that shipped.
  • Statistically testable: a sample can speak, because the agent is not assumed hostile.
  • Adversarial-input exposure: the path needs the Regime 3 check. The plugin does not run that check.
