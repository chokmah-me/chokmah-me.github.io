KEY INSIGHT

💡 HOSTILE PRIOR

Trust is not a verification method.

Every locked gate is built to produce the opposite verdict where the opposite is correct. CI fails loudly on drift either way.

The contribution is the playbook, not the verdicts. PASS carries the same weight as BREAK — the method does not grade on a curve.

⚖️ DISPOSITION TAXONOMY

BREAK — route refuted by gated, controlled witness
GAP — inference broken; statement not falsified
PASS — gate claim independently confirmed
SKIP — not auditable as stated
UNKNOWN — artifacts OK; kernel not re-checkable on our toolchain
Polarity rule: gate verdict ≠ route verdict. Lamé 1847: gates PASS on h(ℚ(ζ23))=3 — that confirmed fact kills the route (BREAK).

⚔️ ATTACK TYPES A–G (mechanism-classified · append-only)

A Scalar gate — best-constant / numerical kill
ex: Tang–Zhang Schatten → BREAK (dual arithmetics)
B Base-case kill — induction never starts
ex: Suman ζ(5) Eq.(48) solutions exist → BREAK
C WZ-certificate audit — re-verify certificate pairs
ex: Jana–Karmakar → PASS (Pochhammer trap caught)
D Finite q-expansion — term-by-term to stated depth
ex: PDN1 Du–Yao → PASS (6,747 divisibility pts)
E CAS-transcript replay — the session is the proof
ex: q-TSPP → tooling-limited; Lean spine instead
F Counterexample search — one witness ends the claim
ex: Baste domination → BREAK (50-vertex; control caught bug)
G Logical-gap exposure — isolate premise; smallest failing instance · “Claim (route, not the theorem)”
ex: Lamé at p=23 · Sun Catalan CAT-G · FRK-UC / LEG-NS prose GAPs

🛡️ EVIDENTIARY DISCIPLINES (scar tissue from real failures)

  • Paper-first: pin SHA-256 of the version of record; never gate a dossier paraphrase (Sárközy lesson — wrong threshold).
  • Discrimination control: a check that cannot fail is not evidence; controls caught real bugs (Baste hardcoded n=NUM_VERTICES).
  • Gate-before-prove: no Lean scaffold until a numeric gate decides the statement is worth proving.
  • Fail-closed replay: hash-pinned inputs; any mismatch fails the lane — no “close enough,” no partial passes.
  • Dual anchors: brute-force tiny cases + second independent implementation (Polya sieve 91/91 chunks; p=2 bug caught).
