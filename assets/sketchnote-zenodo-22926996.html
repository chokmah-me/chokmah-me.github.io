🔎 THE PROBLEM

Peer review checks reasoning, not computation.

Certificates vanish. Scripts go un-replayed. Trust fills the gap where checksums should live.

KEY INSIGHT

💡 HOSTILE PRIOR

Trust is not a verification method.

Every locked gate is built to produce the opposite verdict where that is correct. CI fails loudly on drift either way. PASS weighs the same as BREAK.
