Don't load what you can refuse.

PROBLEM

Agent sessions waste turns on re-reading rules, restating context, and unconstrained output. Supply-chain surface grows with every skill and hook.

KEY INSIGHT

INSIGHT

Three-layer context control: don't-load, compress, cache. Path-scoped rules. Headroom for output compression. Agentic patterns with an explicit verify step.

METHOD

Playbook + hooks + path rules. Token accounting. Supply-chain hardening for third-party skills. Designed for Claude Code; patterns transfer.

FORMAL CORE

context = refuse ∪ compress ∪ cache

RESULTS

Structured workflows that cut conversation turns. Rules fire only on matching paths. Headroom keeps long answers from blowing the window.

LIMITS

A playbook, not a runtime proof. Teams still own review. Version the playbook with the harness.
