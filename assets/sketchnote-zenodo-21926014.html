BELOW THE MASKING THRESHOLD

Phase II · residual IRGC missile force

13 August 2026 · preprint

Sparse provocation can tell active C2 from a pre-programmed residual force. Dense provocation cannot.

KEY INSIGHT

An OSINT attribution-correlation proxy discriminates active command from pre-programmed fire under sparse provocation. The same proxy saturates when provocation is dense.

Phase I asked what destroyed launch rate. Phase II asks what an observer can still tell apart in the residual force.

WHAT THIS BOARD IS NOT

Not the 92 percent launch-rate drop. That number belongs to the Phase I campaign paper. This board is the observability extension.

LIMIT

The proxy is an OSINT construct. Saturation is a property of the proxy, not a proof that dense fire hides every real C2 link.

HOW TO READ THE TWO ROWS

  • Sparse row: few probes, the attribution-correlation proxy still separates active command from a pre-programmed residual.
  • Dense row: many probes, the proxy saturates, and the split disappears.
  • The instrument is OSINT. It is not a sensor on the launcher.

PHASE I STAYS OFF THIS BOARD

Launcher attrition and the launch-rate drop are a different paper. This preprint is the observability question for the force that remains.
