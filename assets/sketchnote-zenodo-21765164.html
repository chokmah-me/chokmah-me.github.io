Invert-and-Affine S-box Class, with the Four ARIA Instantiations

🔎 THE PROBLEM

Nasr–Carlini’s Möbius Bridge drops one guessed key byte from 7-round AES MitM by a fingerprint that survives the S-box.

The derivation is written for the AES S-box: field inversion, then a GF(2)-affine map. ARIA is not that shape.

KEY INSIGHT

💡 CLASS, NOT AES

The construction holds for every invert-and-affine S-box. The Frobenius exponent j is the only degree of freedom.

S = L2 ∘ Frobj ∘ inv ∘ L1

L1, L2 are GF(2)-affine bijections. AES is j = 0 with L1 = id.

⚠️ BAD INDICES MOVE WITH L1

Where inv(0) = 0 breaks the identity, the hole sits at { L1−1(0), s }, not at {0, s}.

For ARIA’s inverse S-boxes those holes are the affine constants. The published AES bad-index treatment does not port unchanged.

🔁 THE BRIDGE MOVE

The same reciprocal-and-reparametrize step as Nasr–Carlini yields an affine bridge identity:

  • both parameters raised to the 2j power
  • the multiplier remains the square of the translation
  • the key byte κ cancels in every pairwise difference

🧷 FINGERPRINT (Cor. 3.2)

Online class-S-box fingerprint equals the offline multiset fingerprint. Power-sum ratio I(m,n) = Pmn / Pnm is invariant across all 255 admissible reference values s (checked at (m,n)=(7,11) and three other pairs).
